# Frontend Mentor - Typing Speed Test Solution

This is a solution to the [Typing Speed Test challenge on Frontend Mentor](https://www.frontendmentor.io/challenges/typing-speed-test). Frontend Mentor challenges help you improve your coding skills by building realistic projects.

### The challenge

This is a simple typing speed test that calculates words per minute (WPM) and accuracy. It takes phrases from a JSON file located in the public/data directory. Also it saves the best user's WPM into local storage. The task is written in README-fm.md file. I worked hard to implement all of the features from this file. The project is located in the **project** directory.

### Development stack

- **Next.JS** - react framework
- **Tailwind CSS** - utility-first CSS framework
- **TypeScript** - typed JavaScript
- **React** - library for creating user-interfaces

### Quick start

1. Repository cloning

```bash
git clone https://github.com/Dotesag/fm-typing-test.git
cd fm-typing-test/project
```

2. Installing NPM dependencies

```bash
npm install
```

3. Launching in dev mode

```bash
npm run dev
```

The application will be available on the **http://localhost:3000** address.
